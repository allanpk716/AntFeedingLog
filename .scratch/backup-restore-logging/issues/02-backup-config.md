# 票 02 · 备份配置：库外元数据 + 设置页自动备份区

Spec：`docs/superpowers/specs/20260918-backup-restore-logging-spec.md`（D1/D10/D11 配置部分）

## What to build

自动备份的"设置与开关"落地：

1. **备份元数据出库（D1）**：开关、备份目录、保留份数、`last_backup_date`、`last_data_write_date`、上次备份结果与时间——全部存数据目录独立文件 `backup-config.json`，**不进 SQLite settings 表**。默认值：开关=开、目录=未设、保留份数=30。
2. **命令**：`get_backup_config` / `set_backup_config`（目录经系统文件夹选择框选取后保存）；`get_backup_status`。
3. **设置页"数据"页签·自动备份区**：开关、目录选择（显示当前目录）、保留份数（数字输入，合理范围校验）、上次备份状态（成功/失败+时间，未备过显示"尚未备份"）。
4. **未生效提示**：开关开着 ∧ 目录未设 → 区内显示"未设置备份目录，自动备份未生效"。

本票只做配置与展示，不实现备份动作本身（票 03）。

## 验收标准

- [ ] 配置改动持久化在 `backup-config.json`，重启后保留；恢复整库不影响该文件（单测：动库不联动配置）。
- [ ] 目录选择走系统文件夹选择框；选完显示所选目录。
- [ ] 开关开+目录未设：显示"未设置备份目录，自动备份未生效"；设了目录后提示消失。
- [ ] 保留份数可改（1–365 范围校验，非法值拒绝并提示）。
- [ ] 上次备份状态展示四态：尚未备份 / 成功+时间 / 失败+时间+原因（本票用手工置入的状态文件验证，票 03 接真数据）。
- [ ] cargo test + 前端组件测试全绿。
