# 头像横幅（乙-2）：卡片顶部大图 + 形状偏好移除

Spec 来源：2026-09-29 拷问会话定案（用户看过 `mocks/mock-avatar-enlarge.html` 选乙-2）。视觉基线即该 mock。

## 一句话

窝卡片头部 40px 圆头像换成顶部整条横幅大图（桌面约 118px / 手机约 150px 高），方形裁剪区放大铺满宽幅（裁剪编辑器仍是唯一真相）；「头像形状」设置项随迁移移除。

## 关键决议

- 渲染：方形裁剪区 cover 宽幅——CSS 方案：横幅内嵌正方形容器（宽=横幅宽、aspect-ratio 1/1、垂直居中），沿用现有 avatarImgStyle 百分比裁剪数学不动
- 名字/物种徽章/状态徽章/天数叠在照片下沿暗色渐变 scrim 上；右上角「巢况」「📷 拍一张」玻璃按钮
- 点横幅 = 开巢况时间线（沿现头像行为）；无照片 🐜 大占位；冬眠卡横幅灰化
- 手机（≤480px 单列）同构，横幅更高（约 150px）
- 「头像形状（圆/方）」全局偏好移除：设置 UI、ipc、Rust 命令、webui 只读白名单、settings 键（v14 迁移 DELETE）
- 窝变多暂不做密度优化（用户知情）

## 验收

- vitest 全绿、vue-tsc 0 错、cargo test 全绿（端口环境例除外）
- mock 对照：横幅布局/信息叠放与 mock 乙-2 一致
