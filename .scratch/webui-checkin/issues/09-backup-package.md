# 票 09 · 数据包备份(manifest 清单驱动)

规格:Implementation Decisions F(打包);User Stories 14

## What to build

- 备份产物升级为单文件 zip 数据包:根 `manifest.json`(格式版本、创建应用版本、时间、库文件名+SHA256、照片清单[相对路径+SHA256]、总张数与总字节)+库+照片(按相对路径)。
- **清单驱动打包**:只收库内引用的照片;打包前校验每张引用照片存在且可读;**读取时文件缺失→跳过该张+错误流水告警,不整包失败**;跳过 `.tmp-`/`.orphan-`。
- 手动"安全备份"与自动备份统一切换到新格式;保留份数语义照旧;pre-restore 旧快照文件格式兼容读取(升级随票 10)。
- 自动备份触发语义不变(元数据提交后)。

## 验收标准

- [ ] 数据包可被 manifest 校验(哈希/张数/字节)
- [ ] 缺文件降级:跳过+流水,包仍完整自洽(manifest 只列实际收入)
- [ ] 自动/手动备份产出同格式;保留淘汰照旧
- [ ] `.tmp-`/`.orphan-` 永不进包
- [ ] 测试齐(tempdir 端到端),既有全绿
