# 票 03 · 网页端设置、网段枚举与防火墙联动

规格:Implementation Decisions B(网段识别/物理网段硬警示/防火墙联动)、G 之外的全部设置面;User Stories 1/3/16

## What to build

- 网段枚举命令:遍历本机网卡,过滤虚拟化噪音(VMware/WSL/Hyper-V);**按接口身份识别虚拟网段**(接口名/提供方=NetBird 即 wt0)置顶标名;**未确认身份的 100.64–127(CGNAT)地址不享受免警示**(CGNAT≠加密隧道)。
- 设置页新增「网页端」分区:总开关(默认关)、受信网段多选(勾任何非"已确认加密身份"网段→强制确认框明示明文风险,不确认不给勾)、端口(默认 17321,1024–65535 校验,占用提示占位于票 04 实装)、服务起停生命周期挂钩(本票落设置与状态,监听由票 04)。
- 访问凭证:数据目录独立 JSON(≥128bit 随机生成;不进库、恢复不触碰);设置页查看(打码/明文切换)、**只可重生成不可自定义**;重生成即旧凭证作废标记;展示完整地址 `http://<所选网段IP>:<端口>/#token=<凭证>` 一键复制+风险提示文案。
- 首次启用向导(装新版后一次,可跳过):选网段→生成凭证→展示地址→触发防火墙。
- 防火墙联动:固定规则名、入站、限定"所选网段+当前端口";改网段/端口→删旧建新;关闭→删规则;失败落错误流水+设置页给现成 netsh 手动命令;UAC 提权执行一次。

## 验收标准

- [ ] 枚举结果:wt0 置顶标名,VMware/WSL/Hyper-V 不出现;未确认 CGNAT 段勾选弹硬警示
- [ ] 凭证文件不入库;重生成后旧值失效标记生效
- [ ] 完整地址含 fragment 形式凭证,复制可用
- [ ] 防火墙 netsh 幂等(重复启用不重复建规则)
- [ ] 枚举/存储/联动纯核有测试;UAC 路径手动冒烟进晨报
