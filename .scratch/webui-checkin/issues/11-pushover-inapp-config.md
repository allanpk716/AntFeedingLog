# 票 11 · Pushover 应用内配置

规格:Implementation Decisions G;User Stories 13

## What to build

- 设置页通知 tab:Pushover 用户键/应用令牌两输入框(打码显示、可切换明文)、"当前生效来源"标注(应用内/环境变量/未启用)、"发送测试"沿用。
