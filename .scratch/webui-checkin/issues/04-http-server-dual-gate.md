# 票 04 · HTTP 服务骨架与双闸准入

规格:Implementation Decisions A(请求限制)、B(闸一/闸二/SSE 票据);User Stories 1/3

## What to build

- 进程内嵌 HTTP 服务:按票 03 设置起停;端口被占用→不启动+设置页/托盘提示。
- **闸一**:全网卡监听;只认 socket 对端地址做网段白名单判定(忽略一切转发头),IPv4 CIDR 匹配,IPv6 默认拒绝。
- **闸二**:Bearer 凭证校验(读票 03 凭证文件;重生成后旧凭证即刻 401);`POST /api/sse-ticket` 主凭证换 60 秒一次性票据(仅约束建连,建连即消费)。
- **白名单默认拒绝**:未登记路径一律 404(本票登记:健康检查、数据版本、sse-ticket;其余随票 05/08)。
- 请求限制:普通请求体 ≤1MB、上传 ≤15MB、普通并发 ≤8、SSE 连接单独计量 ≤4、读超时 30s、header 数与单条长度上限。
- 服务事件(起/停/拒绝)落 applog 流水。

## 验收标准

- [ ] 白名单外来源 TCP 层拒绝;IPv6 来源拒绝
- [ ] 无凭证/错凭证 401;票据一次性且过期拒
- [ ] 未登记路径 404(deny-by-default)
- [ ] 请求限制触发即断开
- [ ] 端口占用不崩溃、有提示
- [ ] 中间件纯核(注入对端地址)测试齐;既有测试全绿
