# 票 05 · 记录类 API 暴露与服务端输入校验

规格:Implementation Decisions A(白名单清单/输入校验)、H;User Stories 4/5/6/7(无照片)

## What to build

- HTTP 端点暴露记录类命令:首页数据(窝列表+超期状态投影)、打卡(字典读+提交)、历史记录(查/改/删)、冬眠操作、巢况登记(查/改/删;照片上传随票 08)。
- **服务端输入校验**(白名单≠校验):ID 正整数、日期格式+范围、分页上限、枚举、字符串长度、数值范围——HTTP 可绕过前端 UI,所有端点独立校验,非法 400 带人话错误。
- 票 01 调用层的 HTTP 实现接入:浏览器打开应用即得完整记录功能(SSE 随票 06;本票允许切页刷新兜底)。
- 写操作成功后沿用既有 tray tooltip 刷新与自动备份触发(经 with_conn 的既有语义不绕过)。

## 验收标准

- [ ] 浏览器内完成打卡→改→删→冬眠→巢况登记全流程(桌面同源测试)
- [ ] 越权/畸形参数一律 400,不落库
- [ ] 未登记命令仍 404
- [ ] 自动备份/托盘刷新在网页端写入后照常触发
- [ ] 前端双模式路由测试;Rust 端点测试齐
