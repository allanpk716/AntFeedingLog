# 票 02 · 窝卡片头像渲染(占位/点击/网页取图)

## What to build
首页窝卡片显示头像,消费票 01 的头像投影载荷:
1. 卡片头部渲染头像:有头像照片时按其裁剪区域(空=居中)以方形裁剪框显示;无头像照片显示 🐜 占位。
2. 显示形状默认圆形(本票硬编码默认;全局偏好开关在票 03 接线,不冲突——本票渲染函数接收形状参数,默认圆)。
3. 点头像 = 打开该窝巢况时间线(复用既有「巢况」按钮同一弹窗)。
4. 网页端头像取图沿用既有 blob 通路(按需取该窝头像一张,凭证不进 URL,卸载释放);桌面走 asset 协议既有通路。
5. 头像不改变卡片其余布局语义(名字/摘要/操作不动)。

## 验收标准
- [ ] 有照片窝:卡片显示头像照片,按裁剪区域定位(无裁剪=居中),方形裁剪框+默认圆形遮罩
- [ ] 无照片窝:显示 🐜 占位,不报错、不显示破图
- [ ] 点头像打开巢况时间线弹窗(与「巢况」按钮等价)
- [ ] 网页端头像正常显示(blob 取图成功;取图失败显示占位不崩溃);桌面 asset 正常
- [ ] ColonyCard 组件测试:头像渲染/占位/点击/裁剪定位 用例齐,先红后绿
- [ ] vue-tsc 0 错;相关 vitest 通过
