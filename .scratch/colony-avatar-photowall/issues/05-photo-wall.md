# 票 05 · 照片墙页(顶层「照片」+ 分区筛选 + 大图连翻 + 查看登记)

## What to build
新顶层「照片」页(桌面+网页):
1. 导航:桌面四页(首页/统计/照片/记录)、网页三页(首页/照片/记录);新增页类型 photos。
2. 页面:消费票 01 的 photo_wall 载荷——按窝分区(窝名标题),窝内按登记日期倒序分组(日期标题),组内按排序契约列缩略图;提供"按窝筛选"(全部/单窝)。
3. 缩略图:整图 cover 显示;按窝分区渲染 + 进入视口懒加载(网页端按需取 blob、卸载释放;桌面 asset+浏览器原生懒加载);文件缺失显示既有"文件缺失"占位风格,不崩溃。
4. 大图:点缩略图打开大图查看器,显示照片+窝名+登记日期;按时间顺序连翻(上一张/下一张,新→旧,范围随当前筛选);提供「查看登记」= 打开该窝巢况时间线(本页只读,无任何写操作、无上传/删除/裁剪入口)。
5. 空态:全库无照片时给空态提示。

## 验收标准
- [ ] 桌面与网页导航均出现「照片」页;桌面统计页仍在,网页仍无统计/设置
- [ ] 分组与排序符合排序契约:窝分区、日期倒序、同日期多登记按创建序倒序、登记内照片按上传序;筛选单窝后仅显示该窝
- [ ] 大图连翻:顺序=列表顺序(新→旧),显示窝名+日期;「查看登记」打开对应窝的巢况时间线
- [ ] 页面只读:不出现上传/删除/裁剪任何写入口
- [ ] 懒加载生效(不进入视口的图片不发起取图);缺图占位不崩溃
- [ ] PhotoWallPage 测试(分组/排序/筛选/连翻顺序/查看登记/空态)与 App 导航测试先红后绿;vue-tsc 0 错
