# 02: 红点角标——落库事实源与按钮红点

**What to build:** 主页面「检查更新」按钮获得红点角标，表达一个事实：「远端有比当前新的版本」。事实源落库持久化：任一现有检查路径（每日自动 / 手动检查）发现新版就把版本号写进 settings 键，结果为已是最新就清键；判活读取时在 Rust 侧做数值语义版本比较（点分段按数值比，落库版本严格大于当前版本才亮）。键变化时向前端广播事件，App 挂载时读一次——重启不丢、离线启动照读。红点只随事实变：检查已是最新即灭、装完重启版本追上自然灭；点「暂不更新」不灭。
