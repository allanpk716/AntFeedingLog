# 大类周期：喂食提醒按大类计时

Spec 来源：2026-09-29 拷问会话定案（用户两轮全确认）。决议与理由见 `docs/adr/0008-category-level-feed-reminder.md`，词汇表已同步（CONTEXT.md：食物大类 / 大类周期 / 距上次 / 建议间隔 / 每窝周期）。

## 一句话

喂任一蛋白质 → 整个蛋白质大类的钟归零；超期只提醒一条「该喂蛋白质了」。种子 7 / 蛋白质 3 / 糖水 3，设置页按大类可配（可清空=不提醒）。

## 关键决议

- 提醒粒度：大类层取代食物层；food.suggested_interval_days 废弃（v14 迁移 DROP）
- 大类周期存 `food_category_interval` 表；迁移初值 = 大类内食物间隔最大值（宽松优先）
- 台账：kind `food_overdue` → `category_overdue`，food_id 维度换 category key；存量行迁移时归并（同窝同操作同基准日留一条）
- 文案：通知「该喂蛋白质了 / 已 N 天没喂蛋白质（建议 3 天一次）」；卡片 pill「⚠ 该喂蛋白质、糖水了」
- 逐食物「距上次」降级为喂食块悬停参考，不驱动提醒
- 不提供每窝大类周期；与统一周期「任一超期即提醒」叠加语义不变
- 统计页无需改动（间隔图只含操作层）
