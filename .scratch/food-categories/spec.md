# 食物两层分类（food-categories）

Status: done（2026-09-29；验证：cargo 655/656 唯一败=端口环境例、vitest 777/777、vue-tsc 0 错、真实库副本迁移冒烟通过）

## 背景

食物原为扁平可扩展清单（预置：种子、干虾仁、面包虫）。改为「大类 → 子项」两层结构，选择界面按大类分组。
决策记录：docs/adr/0007-food-two-level-taxonomy.md；词汇表已更新（CONTEXT.md：食物大类 / 食物 / 易腐）。

## 决策摘要

- 大类固定三种：种子（seed）、蛋白质（protein）、糖水（sugar）；不可增删改名，不参与提醒，仅作分组容器。
- 子项沿用字典规则：预置不可删、可改名可停用、可自建（自建项须归入一个大类）。
- 预置七项及默认值：

| 大类 | 子项 | 易腐/撤食 | 建议间隔 |
|---|---|---|---|
| seed | 种子 | 否 | 7 天 |
| protein | 虾干（原「干虾仁」改名） | 24h | 3 天 |
| protein | 面包虫干（原「面包虫」改名） | 24h | 3 天 |
| protein | 樱桃蟑螂（新增） | 24h | 3 天 |
| sugar | 蜂蜜、冰糖水、白糖水（新增） | 24h | 3 天 |

- 旧数据迁移：按名归组+改名（干虾仁→虾干、面包虫→面包虫干），id 不动，log_food 历史引用不断；撞名不改（防 UNIQUE 失败），自建行与新预置同名时原位升格（v8 撤食先例）。
- 提醒、待撤食、统计全按子项算，大类不参与。
- UI：打卡与编辑弹窗按三组一屏直选（多选照旧，空组不渲染组头）；展示面只显子项名；设置·食物每行加大类下拉（行内可改），新增行必选大类（不预填）。
