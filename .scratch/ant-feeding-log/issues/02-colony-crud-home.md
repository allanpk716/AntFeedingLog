# 票 02 · 窝与地点管理 + 首页卡片

## What to build

端到端的"窝"管理：新建/编辑窝（名字 trim 后全局唯一、物种、地点、开始饲养日期、状态），地点清单的增改排序；首页按地点分组渲染窝卡片（分组顺序=地点清单顺序，空地点归"未分组"排最后），卡片含名字、物种徽章、状态徽章、饲养天数大数字（今天−开始饲养日期的自然日天数，含冬眠）；已结束的窝进首页底部折叠区（默认折叠可展开）；没有任何记录的窝可删，有记录的窝只能置"已结束"。操作块本票不需要（票 03）。

## 验收标准

- [ ] 建两个不同地点的窝，首页分组正确、顺序随地点清单
- [ ] 重名窝（含首尾空格差异）被前后端双重拦截
- [ ] 饲养天数计算正确（有测试）
- [ ] 已结束的窝出现在底部折叠区，展开可见
- [ ] 无记录窝可删；给窝造一条记录后删除被拒（Rust 测试）
- [ ] 名字唯一性有 Rust 测试
