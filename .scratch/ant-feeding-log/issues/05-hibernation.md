# 票 05 · 冬眠管理

## What to build

开始冬眠（填开始日期 + 预计结束日期，选完开始日自动预填默认结束日可改）；确认出眠（回填实际结束日期，可与预计不同）；全部约束：同窝冬眠段不得重叠、结束日期不早于开始日期、每窝至多一段开放段（实际结束为空）、已结束的窝不可开始冬眠、状态联动（开始→冬眠、确认出眠→活跃）；首页冬眠态卡片（灰化 + 横幅：入眠日/预计出眠/剩余天数）；冬眠期间提醒静音（红绿态隐藏，显示静音说明）；出眠后提醒类"距上次"基准 = max(最近一次记录, 出眠日期)（出眠当天显示 0 天，不会全红）；间隔统计扣除与冬眠段重叠的天数（多段各自适用）——此计算放 Rust 并导出给统计用。

## 验收标准

- [ ] 约束全组 Rust 测试：重叠拒绝、日期先后拒绝、二段开放拒绝、已结束窝入眠拒绝
- [ ] 状态联动测试：开始冬眠后状态=冬眠；确认出眠后=活跃且实际结束回填
- [ ] 出眠当天卡片显示"距上次 0 天"（基准=max(最近记录,出眠日)，测试）
- [ ] 间隔扣除：跨 30 天冬眠的两次喂食，间隔 = 实际天数 − 重叠天数（含两段冬眠用例，测试）
- [ ] 冬眠中卡片灰化、无红绿态、仍可记账
