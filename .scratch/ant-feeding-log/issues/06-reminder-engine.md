# 票 06 · 提醒引擎与托盘概要

## What to build

Rust 侧提醒引擎：应用启动立即检查一次 + 常驻期间每 30 分钟（Rust 定时任务，不经前端定时器）；三类提醒——提醒类操作超期、临近出眠（预计出眠日前 N 天起，N 默认 7 可配）、出眠日当天；已发台账身份=(窝,种类,操作,基准日) 去重：超期每个超期日最多一条、临近一次、出眠日一次；修改预计出眠日后未发的临近/出眠提醒按新日期重算（删除未发记录），已发不追回；出眠提醒仅对状态=冬眠的窝生效（提前出眠后不再触发）；错过检查的补发：每窝每种只补最新一条且基准日在近 7 天内；Windows 系统通知默认开；设置模型含通知总开关/超期分类/冬眠分类（默认全开）；托盘图标悬停 tooltip 显示一句话概要（如"2 窝活跃 · 大头一号喂食超期 1 天"）。

## 验收标准

- [ ] 台账身份去重 Rust 测试（同日不重发、临近只发一次）
- [ ] 改预计出眠日：未发提醒按新日期重算、已发不追回（测试）
- [ ] 提前出眠后临近/出眠日提醒不再触发（测试）
- [ ] 补发上限：模拟 10 天未启动，只补最新一条且 7 天窗外不补（测试）
- [ ] 出眠日/超期通知真实发出（手动冒烟，Windows 通知）
- [ ] 通知开关（总/分类）在设置模型生效并持久化；关闭后不再发
- [ ] 托盘 tooltip 概要与首页状态一致（手动冒烟）
