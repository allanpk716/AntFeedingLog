# 票 07 · 统计页

## What to build

统计页四块 + 筛选（按窝或全部、按时间范围）：① 日历热力图（一天一格、颜色=当天操作数、悬停显示日期与当天记录明细）；② 喂食构成占比环形图——各食物出现次数 ÷ 范围内食物出现总次数（归一化 100%），图例同时显示各食物次数；③ 每周操作次数柱状；④ 各操作实际间隔 vs 建议间隔（间隔已扣冬眠天数，仅提醒类画建议刻度，登记类标"仅登记"）；频率类数字（如"平均每天 X 次"）分母 = 筛选范围自然日天数，界面标注口径。

## 验收标准

- [ ] 占比各分项合计 = 100%（多选食物按出现次数计，前端单测）
- [ ] 间隔数字与票 05 的 Rust 计算一致（同一函数/同一结果）
- [ ] 热力图悬停明细含喂食的食物
- [ ] 空数据/单天范围不崩溃不变形
- [ ] 筛选（某窝/近 3 月）后全部图表联动
- [ ] 频率口径标注可见
