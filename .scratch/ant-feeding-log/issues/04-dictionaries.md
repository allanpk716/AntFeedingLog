# 票 04 · 字典管理与操作性质设置

## What to build

设置页的字典管理：操作/食物/地点三项的增、改显示名、排序；删除规则——未被任何记录/窝引用可物理删除，被引用只能"停用"；停用项不再出现在新建记录入口与筛选默认项；操作的性质切换（提醒/仅登记）与建议间隔编辑；切换性质后首页卡片红/灰即时变化。

## 验收标准

- [ ] 停用某食物后，喂食弹窗不再出现它
- [ ] 引用过它的历史记录展示不受影响（名称保留）
- [ ] 未被引用的项可删，被引用的删除被拒（Rust 测试）
- [ ] 把"活动区换水"切成提醒类+3 天后，卡片相应块出现红绿态
- [ ] 改名后历史记录跟随新显示名（id 不变，测试断言）
