# 票 03 · 一键记账与喂食弹窗

## What to build

首页卡片上的动态操作块（每个"启用中"的操作类型一块，2 列自适应网格，字典新增操作自动出现块）：点非喂食操作一键记账；点喂食弹出食物多选（chips）+ 时间（默认现在、可补录改）+ 备注（可选），确认生成一条记录挂多种食物。每块显示"距上次 X 天"：提醒类绿（正常）/红（超期，超建议间隔）/今天·已记录；登记类中性灰 + "仅登记"角标，永不红；冬眠中的窝显示静音态（票 05 接管横幅）。卡片底部显示最近 1-2 条记录摘要。任何记录变更后界面即时重算（数据驱动）。

## 验收标准

- [ ] 一键记账后对应块变"今天 · 已记录"
- [ ] 喂食一次勾两种食物 → 一条记录、两个食物关联（Rust 测试）
- [ ] 补录昨天时间 → "距上次"按发生时间计算
- [ ] 喂食距上次 4 天（默认建议 3）显示红色超期
- [ ] 登记类操作无论多少天都不红
- [ ] 操作块随字典启用项动态渲染
- [ ] 发生时间与录入时间分开存储（schema 断言）
