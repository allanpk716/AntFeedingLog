# 票 09 · 托盘常驻、设置页收口、备份与导出

## What to build

托盘常驻行为：点窗口关闭 = 最小化到托盘（不退出），托盘右键菜单含"显示窗口/退出"；开机自启默认开（设置可关）。设置页收口呈现全部设置：通知总开关/超期分类/冬眠分类（接票 06 的模型）、临近出眠提前天数、开机自启、"打开数据文件夹"按钮、"安全备份"按钮（由 Rust 复制库文件到用户选定目录——无 WAL，拷贝即完整）、"导出 CSV / JSON"（归档定位，CSV 行数=记录数）；帮助文案写明手动拷贝备份需先从托盘真实退出。

## 验收标准

- [ ] 关窗后进程仍在托盘；右键退出才真退出（手动冒烟）
- [ ] 开机自启默认开、可关（注册表/启动项佐证）
- [ ] 安全备份产物可被应用重新打开读取（拷贝完整性测试）
- [ ] 导出 CSV 行数=记录数、JSON 可被解析（测试）
- [ ] 全部设置持久化并重启后生效
- [ ] 设置页能到达所有上述入口
