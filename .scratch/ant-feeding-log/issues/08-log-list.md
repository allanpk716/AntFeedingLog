# 票 08 · 记录列表页

## What to build

记录流水页：按窝/操作类型/时间范围组合筛选 + 备注关键词搜索；行内编辑（发生时间、操作、食物、备注）与删除；停用的操作/食物在编辑表单中照常出现（带"已停用"标记）且可保留原值；任何编辑/删除后首页"距上次"与超期态即时重算。

## 验收标准

- [ ] 三条件组合筛选 + 备注搜索正确（前端单测筛选拼装逻辑）
- [ ] 编辑喂食记录更换食物生效（Rust 测试关联更新）
- [ ] 删除最后一条记录后，对应操作块"距上次"变为无记录态
- [ ] 引用停用项的旧记录：列表正常显示、编辑表单可见可选（标已停用）
- [ ] 补录到过去时间后，首页红绿态按新发生时间重算
