# 票 03 · 轻提示(Toast)模块 + 设置页接线与提示行

## What to build
建立全局唯一的应用内轻提示模块并完成设置页整页接线:toast store(成功/失败 API、自动消失计时——成功绿约 2.5 秒/失败红约 5 秒带原因可点 × 提前关、同屏至多 3 条更早先走)+ 展示组件挂应用根(底部居中浮层,不挡操作区),桌面端与网页端同一前端同享。设置弹窗接线:「保存」成功弹"已保存"、失败弹红色带原因(**撤除旧的内联失败红字**,字段级校验错误维持内联——通道迁移 F3);操作/食物行级 停用/启用/删除 即时落库补成功/失败轻提示;数据 tab 的安全备份、导出 CSV/JSON、清理孤儿照片补成功/失败轻提示(有自身进度/结果回显的以判定原则审计,天然反馈足者不弹)。同时在「操作」tab 顶部加常驻提示行"同一操作各窝节奏不同时,编辑某个窝可单独设「每窝周期」,优先于此处的全局设置",并把"仅登记"下拉 tooltip 补全为"只记录,本页不催促;单个窝仍可在窝编辑里设周期提醒"。

## 验收标准
- [ ] toast store 行为用例:成功/失败样式档、自动消失、提前关、同屏 3 条上限与先走
- [ ] 组件挂应用根,桌面与网页入口都渲染(网页端为同一前端,断言挂载即可)
- [ ] 设置「保存」成功有"已保存"轻提示;失败走红色带原因轻提示;旧内联失败红字已撤;字段校验错误仍内联
- [ ] 行级 停用/启用/删除 各有成败轻提示
- [ ] 安全备份/导出/清理孤儿照片按判定原则接线(无天然反馈者弹,已有结果回显者在测试中说明不弹的理由)
- [ ] 「操作」tab 顶部提示行存在;"仅登记" tooltip 文案含"单个窝仍可在窝编辑里设周期提醒"
- [ ] 打卡/删除记录等有天然反馈的操作不被接线(无 toast 调用混入)
- [ ] vitest(涉及文件)全绿 + vue-tsc 0 错
