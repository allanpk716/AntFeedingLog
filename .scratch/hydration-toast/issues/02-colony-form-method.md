# 票 02 · 前端窝表单:保湿方式选择器 + 状态矩阵交互

## What to build
把保湿方式接进窝的新建/编辑表单,实现规格状态矩阵的九条交互规则:窝编辑「周期提醒」小节里巢穴保湿那一行变为"方式下拉(未设/手动加水/水塔)+ 天数输入(可改)",其余操作行保持纯数字输入;新建表单带方式选择,周期按默认随建随落,保存走票 01 的原子命令(types/ipc 契约对齐)。关键交互:打开编辑按库内原样回显不自动预填;显式选方式时空框预填默认(手动 7/水塔 15)、非空不动;未保存期间切换方式时预填值跟新方式、手工改过或库内值不动;**空框切换(D 态)即预填新方式默认**;显式清回未设——库内原值非未设时周期框同步清空置灰且保存删周期行,库内原值=未设时"选了又改回"净效果为零;只清天数=留方式不提醒;未触碰方式的保存原样往返。选择器旁一句说明文案。卡片零改动。

## 验收标准
- [ ] 编辑模式:库内(方式,周期)四态 A/B/C/D 回显正确,打开不自动预填
- [ ] 规则 2/3/7/空框切换(F5):预填、不覆盖、切换跟随、手工改过不动的交互用例全过
- [ ] 净零语义(F4):库内未设+周期 N,会话内选方式又改回未设,保存后周期仍为 N;库内 C 态清回未设,周期框清空置灰、保存后周期行删除
- [ ] 只清天数:方式保留、保存后不提醒
- [ ] 新建:未选方式不落周期;选方式默认周期可改;保存走原子命令一次落库
- [ ] 改名等无关编辑保存后保湿配置原样往返(既有用例不回归)
- [ ] 提交前整组校验、只发改动行等既有行为保持
- [ ] vitest(涉及文件)全绿 + vue-tsc 0 错
