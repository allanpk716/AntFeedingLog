# 应用壳选 Tauri 2（弃 Electron、弃本地服务+浏览器）

需求是 Windows 单机、常驻任务栏托盘、界面用 web 前端实现、单用户、已确认不需要手机/局域网访问。选 Tauri 2：安装包 ~10MB、常驻内存低（复用系统 WebView2）、原生托盘支持，壳层 Rust 代码基本只有配置，业务逻辑全在前端（Vue 3）+ SQLite 插件，且本机 Rust 工具链已就绪。弃 Electron：功能等价但安装包 ~80MB、常驻内存 150-200MB。弃"本地服务+浏览器"：托盘常驻名存实亡。

> 2026-09-19 修订：**"已确认不需要手机/局域网访问"的前提已被 ADR-0003 反转**（进程内嵌网页端，托盘常驻不变）；Tauri 2 壳的选型结论维持。
