# 食物两层结构：大类固定三种，子项才可扩展

喂食的食物从扁平清单改为两层：每样食物必归入一个食物大类，大类固定三种——种子、蛋白质、糖水——写死在 schema 约束与校验里，不做增删改；可扩展的只有大类之下的食物项（沿用字典规则：预置不可删、可改名可停用、可自建，自建项须归入一个大类）。大类只是分组容器：距上次、食物周期、待撤食全部按子项计算，大类不参与任何提醒逻辑。

## Considered Options

- **大类也做成字典（可增删）**：被否。饲养实践里食物来源就这三类，做成字典要为大类单独造一套 CRUD、停用、排序与管理界面，还要回答"大类停用后子项怎么办"这类边角；写死换来选择界面、迁移与校验的全面简化。将来真出现第四类再改代码（CHECK 约束、展示映射、分组顺序三处），成本可控。
- **维持扁平清单**：被否。食物从 3 种扩到 7 种后，打卡面板的扁平多选会越来越难扫，分组是本次改版的直接动机。

## Consequences

- 大类在库里存稳定英文 key（seed / protein / sugar），展示层映射中文；食物名可改、大类名不可改，key 不受食物改名影响。
- v12→v13 迁移一并落地：预置改名（干虾仁→虾干、面包虫→面包虫干）、全部预置归组回填、新增四个预置子项（樱桃蟑螂、蜂蜜、冰糖水、白糖水，均 24h 易腐）、建议间隔改值（种子 3→7 天；蛋白质类 7→3 天、糖水类 3 天）。
