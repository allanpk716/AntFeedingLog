# 垃圾清理打卡可附带撤食（联动，不合并）

实际饲养中一次开盖清理垃圾区通常顺手收走旧食，两次打卡繁琐；但 20260919 共识 Q1 刚把「撤食」立为独立预置操作、与「垃圾清理」严格区分。决定：两个动作保持独立、各生成一条记录，仅在垃圾清理打卡面板提供「顺带撤走易腐食物」勾选——已逾期默认勾、未到期默认不勾、无待撤不显示（随补录所选时刻动态重算）；补录仅在所选时刻晚于该窝最近一次易腐喂食时生效；仅垃圾清理单向带动；两条记录事后各自独立删除；撤食操作停用时联动一并关闭。

否决了合并成单一动作（会推翻待撤食派生模型、三态卡片与易腐间隔整套设计）与纯自动附带（食物未到期时清垃圾多半不收还在被吃的食物，错误记撤食会清空待撤状态、放走发霉风险——正是该功能防的事）。词汇表同步见 CONTEXT.md「撤食」「垃圾清理」词条。
