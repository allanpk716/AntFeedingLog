# 界面切换卡顿修复（设置弹窗 + 主界面页签/页面）规格

日期：2026-09-28 · 状态：已评审收敛（两轮：盲评 + 限定复审） · 来源：会话共识 + xcheck 链 20260928-150710/151927

## Problem Statement

用户在设置弹窗内切换子页签时，内容不是立即出现，要等一下，感知卡顿；同类问题存在于主界面导航页（统计/照片/记录）与记账/打卡弹窗。具体病灶：

1. 页签/页面用 `v-if` 挂载——切走销毁、切回重建并重走 IPC 读数据（设置弹窗「网页端」「更新」页签与主界面三页每次进入都重拉）。
2. 读取过程无任何提示——空白或先显示默认值再跳成真实值（网页端页签先显默认端口 17321、开关全关）；设置弹窗刚打开时默认页签也是空白。
3. 设置弹窗打开的加载链是串行（主链后还串五段），首屏内容出场被拖慢。
4. 页签切换销毁面板导致未保存的修改丢失（网页端表单、地点面板改名）。
5. 统计页有 loading 标志但从未渲染；记录页空态与加载期不分；孤儿照片区在"还没读完"时误显「读取失败」。
6. 照片墙页没有订阅数据版本广播，靠每次进页重挂载硬保鲜（统计/记录页已有订阅）。

## Solution（用户视角）

- 切换界面时内容**立即出现**：该缓存的缓存（设置弹窗面板保活、主界面三页保活），再进入不重新读。
- 必须读数据的**首次进入显示「加载中…」占位**：不空白、不闪默认值；数据一到即出内容。
- 设置弹窗里**未保存的修改切页签不丢**；弹窗关闭后再开重新读。
- 别端（手机网页端）或恢复操作改了数据，电脑上**开着的页面自动刷新**。

## User Stories

1. 作为饲养者，我想在设置弹窗里切换任意页签时内容立即出现，以便快速调整配置不被等待打断。
2. 作为饲养者，我想在设置弹窗首次打开时看到「加载中…」而非空白列表，以便知道应用在读数据而不是坏了。
3. 作为饲养者，我想在「网页端」页签直接看到真实配置而非先默认值再跳变，以便不误读端口与开关状态。
4. 作为饲养者，我想在设置页签间临时切换后返回时保留未保存的表单修改，以便多页签对照填写不丢稿。
5. 作为饲养者，我想在主界面统计/照片/记录页间来回切换时内容立即出现（首次进入显示加载中），以便浏览流畅。
6. 作为网页端用户，我想让电脑上开着的照片墙/统计/记录页自动跟上我刚记的数据，以便两端看到同一份新鲜数据。
7. 作为饲养者，我想在恢复备份后已开着的页面自动刷新，以便不被旧数据误导。
8. 作为饲养者，我想在记录页筛选后（结果为空时）看到加载提示，以便区分"还在查"与"没有符合条件的记录"。
9. 作为饲养者，我想在记账/打卡弹窗打开、字典选项未到时看到加载提示，以便选项出现前不困惑。

## Implementation Decisions

- **共用加载占位组件**：新增 `src/components/LoadingHint.vue`（纯文字「加载中…」+ 同名测试）；所有新接入点复用；巢况登记/照片墙/照片裁剪器既有「加载中」样式不迁移。
- **占位判定口径**（对齐"数据已在内存即时渲染"细则）：内容需异步读取**且当前无可显内容**时显示占位；数据已在内存（含旧数据在屏的刷新）即时渲染不显示；**占位退出用独立的"首次读取完成"布尔标志判定，不得用列表长度**（字典合法为空时不能永久卡在加载中）。
- **设置弹窗 SettingsDialog.vue**：
  - 地点/网页端/更新三个页签分支 `v-if` → `v-show`（急挂载）：弹窗一打开即在后台并行挂载读取；切换不销毁面板（未保存修改保留）；弹窗关闭整体销毁、下次打开重读。
  - 打开加载链并行化：`load()` 与 Pushover 状态/头像形状/日志区/备份配置/孤儿照片五段同批并行，各段既有失败语义不变（主链失败轻提示、辅助区静默）。
  - 默认页签（操作/食物）初始字典未到时显示占位、不渲染空列表。
  - 孤儿照片区：加载中显示占位，读取失败才显示「读取失败」。
- **WebUiPanel / UpdatePanel**：数据到齐前渲染占位、不渲染表单（消灭默认值闪现）。
- **主界面 App.vue**：统计/照片/记录三页包 `<KeepAlive>`（懒保活：会话内首次进入读取+占位，再进即时）；首页不动。
- **PhotoWallPage.vue**：补 `watchDataVersion` 订阅（对齐统计/记录页做法），保活后后台自动刷新。
- **StatsPage.vue**：渲染既有 loading 标志——仅首次读取（payload 为空）显示占位；已有数据时的刷新不显示。
- **LogListPage.vue**：加载中**且当前无行可显**时显示占位（覆盖首载与"空态后再筛选"）；有旧数据在屏不显示。
- **FeedDialog / QuickLogDialog**：字典选项区读取期间显示占位。
- **规范沉淀**：CLAUDE.md 增「加载态判定原则」（与操作反馈规范并列，措辞见决策 D5）；CONTEXT.md 增「加载态（Loading State）」词条。
- **Rust 零改动**：全局库锁不动（急挂载三面板的读取不走库锁已核实；走库的读取毫秒级）。

## Testing Decisions

只测外部行为（组件渲染与数据流），不测实现细节；沿用仓库"组件与同名 `*.test.ts` 同目录（Vitest）"惯例：

- LoadingHint：渲染「加载中…」文本。
- SettingsDialog：打开即挂载三个面板（后台读取）；默认页签占位出现与退出（**含空字典场景——首次读取完成后退出占位**）；页签来回切换面板不重挂载（未保存修改保留）；并行化后各段失败语义维持（主链失败轻提示、辅助区静默）；孤儿区加载中显示占位、失败显示「读取失败」。
- WebUiPanel / UpdatePanel：配置到齐前渲染占位、不渲染表单。
- App：页面切换后重进不重挂载（IPC 不重发/状态保留）。
- StatsPage：首次读取显示占位；已有数据刷新不闪占位。
- LogListPage：首载与空态重查显示占位；有旧数据在屏的刷新不显示；筛选变更场景覆盖一次。
- PhotoWallPage：数据版本广播触发重拉。
- FeedDialog / QuickLogDialog：字典未到显示占位。
- 全量口径：`pnpm test`（vitest run）全绿 + `pnpm exec vue-tsc --noEmit` 0 错；Rust 无改动，`cargo check` 兜底跑一道。
- 验收含：恢复或别端写入后，已开着的页面自动刷新。

## Out of Scope

- 首页卡片照片的每卡一跳 IPC（异步协议重设计，单开一摊）。
- Rust 侧锁/调度任何改动。
- 既有三处「加载中」样式的迁移统一。
- 骨架屏/转圈等其它加载形态。
