## 二、机制细则（rev1 新增/钉死）

### 触发与重试（钉死单一规则，修 #1 #2 #6）

- **触发点只有两处**：①业务写入完成后（记录 / 窝 / 字典 / 冬眠的增删改——**元数据写入不算**：备份状态、设置、提醒台账等不触发）；②应用启动时。
- **触发条件（单一谓词）**：`开关开 ∧ 目录已设 ∧ 今日（本地日期）尚无成功的自动备份`。满足即执行备份。
- 语义推论：当日第一次业务写入 → 备份；当日后续写入 → 已有成功备份，跳过（**不重备、不覆盖**）；备份失败 → "今日无成功备份"仍成立 → 当日后续每次业务写入与下次启动自动重试；当日再无写入 → 次日首次写入 / 下次启动重试。
- "今日是否已有成功备份"由备份成功时写入的 `last_auto_backup_date`（settings 键）判定；该写入属元数据，不构成触发（触发点只挂在业务写入上，判定不依赖库文件时间戳对比，无自触发回路）。

### 备份执行协议（修 #13 #14）

1. 短暂拿锁 → 库文件拷到数据目录临时文件（本地拷贝，实验实测 MB 级毫秒级完成）→ 释放锁。
2. 锁外把临时文件拷到备份目录（目标目录是网络盘/慢速盘也不占用库锁、不阻塞记录与 UI）。
3. 成功：删临时文件、更新 `last_auto_backup_date` 与"上次备份状态"；失败：静默记失败（状态含失败原因与时间），临时文件清理，待下次触发重试。
4. 命名：自动备份 `ant-feeding-log-backup-YYYYMMDD-HHMMSS.db`（含时分秒，杜绝同日同名覆盖）；保留策略（Q4）按文件时间排序淘汰最旧。手动备份沿用现状（文件名到日期即可——系统保存对话框自带覆盖确认）。

### 恢复协议（五步，修 #3 #9 #10）

1. **源校验**：拒绝"源路径 == 当前库路径"（防自恢复）；把源文件复制到数据目录 `restore-staging-<时间戳>.db` 临时文件（此后一切校验都在临时库上，全程不碰当前库）。
2. **临时库校验**：可打开（非 SQLite/0 字节 → 拒绝"这不是本应用的备份"）；`PRAGMA integrity_check` 返回 ok（页损坏 → 拒绝"备份文件已损坏"）；schema 版本判定——旧版本 → 在临时库上执行 `open_and_migrate` 升级后复校；比当前程序新 → 拒绝"这是未来版本的备份，请先升级应用"；无法读取版本 → 拒绝。
3. **pre-restore 快照**：当前库拷一份 `pre-restore-<时间戳>.db` 到数据目录（防恢复错了想反悔），**最多保留最近 3 份，超出删最旧**（修 #7 #8）。
4. **单点替换**：短暂拿锁 → 关闭旧连接 → 以"先写新文件再原子改名"的方式把 staging 换入库文件位置 → 重建连接 → 广播各页刷新（Q13：刷新链路过绕则降级"提示重启生效"）。
5. **失败语义**：第 1–3 步任一步失败 → 当前库零改动、清理 staging、向用户报具体原因；第 4 步替换是唯一写动作且发生在全部校验通过之后，采用先写后改名，替换中途失败当前库文件仍在（改名前的原文件未被破坏）——**"自动回滚"由协议结构保证：替换前当前库从未被改动**。
6. 摘要预览（Q6 第二道保险）在步骤 2 完成后展示：备份日期（文件时间/库内最新记录）、窝数、记录数，以及**备份内的备份目录设置值**（Q14 已知后果点明）。

### 异常退出判定（修 #4 #5）

- **运行标记**：启动时在数据目录写运行标记文件（含启动时间）；托盘"退出"正常退出路径清除标记。下次启动发现标记残留 → 判定"上次异常退出"，在设置页日志区显示时间。
- **可捕获异常**：Rust panic 钩子、前端未捕获异常转发 Rust——写入日志文件（含一行原因，Q10 展示用它）。
- **覆盖面如实声明**：强杀（任务管理器）/ 断电 / 原生崩溃（SEGV / 栈溢出 / WebView2 崩溃）**没有日志可写**——这类场景靠运行标记仍能识别为"异常退出"，只是没有原因行，显示"上次异常退出：<时间>（无崩溃日志，疑强杀/断电）"。不承诺硬崩溃有崩溃日志。
- 脚手架 release profile 的 `panic = "abort"` 此前已注释（恢复 unwind 语义），panic 钩子可靠。

### 设置页（修 #11）

- "数据"页签三区：**自动备份区**（开关 / 目录选择 / 保留份数 / 上次备份状态；**开关开 ∧ 目录未设时显示提示文案"未设置备份目录，自动备份未生效"**）+ **现有手动三按钮**（安全备份 / 导出 CSV / 导出 JSON，行为不变）+ **"从备份恢复"按钮**；**日志区**（打开日志文件夹按钮 + 最近错误摘要 + 上次异常退出显示）同页签。
- 更换备份目录不迁移旧目录中的既有备份；保留份数按当前目录独立计算。
- 恢复选文件时，文件对话框默认定位到备份目录（已设置时）。

### 日志（沿用决议，细则）

- 位置：数据目录 `logs/` 子目录，纯文本，按天滚动，自动删超过 14 天的旧文件。
- 动作流水首版事件清单：备份成功 / 失败、恢复执行（含来源文件）、更新检查 / 下载 / 安装结果、开机自启同步结果、提醒发出、手机推送补发 / 作废、启动与正常退出（配合运行标记）。
