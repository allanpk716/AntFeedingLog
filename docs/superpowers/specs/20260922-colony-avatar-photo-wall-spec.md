# 窝头像与照片墙 实施规格

日期:2026-09-22 · 来源:设计共识(rev1,评审两环收敛)+ 决策快照 D1~D11 + FINDINGS F1~F6 · 术语以 CONTEXT.md 词汇表为准(窝头像/照片墙/巢况登记/巢况照片/轻提示)

## Problem Statement

窝卡片只能靠名字认窝——"看文字是哪个巢穴不如看图更快";照片散在各窝的巢况时间线里,想集中回看"巢穴随日期怎么变的"没有统一入口。

## Solution(用户视角)

1. **窝头像**:首页每窝卡片显示头像 = 该窝最新一张巢况照片,自动跟随、无需设置(想换就传新照片);没照片的窝显示 🐜 占位;点头像打开该窝巢况时间线。头像显示形状(圆形,默认/方形)是全局偏好,在设置里选一次;每张照片可调"头像裁剪"(拖动+缩放,想调才调,不调默认居中)。
2. **照片墙**:新顶层「照片」页,全部窝的照片按窝分区、按登记日期倒序集中回看,可按窝筛选;大图按时间连翻(新→旧),标窝名+日期,可跳「查看登记」;只读——上传/删除/调裁剪都不在此页。

## User Stories

1. 作为饲养者,我想在首页窝卡片看到每窝的头像(最新巢况照片),以便一眼认巢、不读文字。
2. 作为饲养者,我想让头像自动跟随最新一张巢况照片而无需任何"设置头像"操作,以便传新照片即换头像、零管理。
3. 作为饲养者,我想删除登记后头像自动退回更早的照片(且那张照片调过的裁剪仍生效),以便怎么删历史都不留悬空头像。
4. 作为饲养者,我想没传过照片的窝显示 🐜 占位,以便一眼看出哪窝还没有照片。
5. 作为饲养者,我想在设置里选头像形状(圆/方)一次全局生效,以便统一外观且上传流程从不受打扰。
6. 作为饲养者,我想对照片拖动+缩放调整头像裁剪,以便头像露出巢的关键部分(桌面鼠标与手机网页触摸都可)。
7. 作为饲养者,我想新照片默认居中裁剪直接当头像、想调才进编辑器,以便拍照上传保持一步到位。
8. 作为饲养者,我想从巢况时间线的大图查看器进入裁剪调整,以便看图与调图同地。
9. 作为饲养者,我想点头像直达该窝巢况时间线,以便最快到达照片管理入口。
10. 作为饲养者,我想在一个「照片」页看到所有窝的照片按窝分区、按日期倒序,以便统一回看哪些日期拍了什么。
11. 作为饲养者,我想按窝筛选照片墙,以便专注看某一窝的巢穴变化。
12. 作为饲养者,我想在大图里按时间连翻(新→旧)并看到窝名+日期,以便像翻相册一样看巢的演变。
13. 作为饲养者,我想从照片墙大图跳到该照片所在的巢况登记(「查看登记」),以便需要删除/调整时一步到达。
14. 作为饲养者,我想在手机网页端也能用照片墙和头像,以便不在电脑前也能回看与识别。
15. 作为饲养者,我想调完裁剪立刻看到保存结果(轻提示),以便确认调整已生效(尤其调的不是当前头像那张时)。

## Implementation Decisions

- **排序契约(评审修复 F1 固化,全链唯一依据)**:登记全序 = 登记日期倒序,同日期按登记创建序号倒序(后建的在前);照片列表全序 = 按照片序号正序(先传的在前)。与既有实现一致,不是新规则。
- **头像派生(投影,不落库)**:按登记全序扫描,取**第一条含照片的登记**的照片列表第一张(评审建议 F6 补严:跳过无照片的纯文字登记;与"最新一张巢况照片"原义一致);该窝从无照片则无头像(显示占位)。首页窝列表载荷为每窝附头像照片引用(照片相对路径+裁剪);桌面与网页同源,前端不重复推导。
- **裁剪数据**:随每张照片存——归一化方形区域(x、y、边长,0~1);空缺 = 默认居中。圆形显示 = 方形区域挖角;全局形状切换无需重调裁剪。
- **schema v11→v12 迁移(评审建议 F3)**:照片表新增裁剪三列(可空),存量行为空(即居中),不回填;迁移幂等,旧库升级不丢照片。
- **裁剪更新通路**:新命令"更新照片裁剪"(照片 id + 裁剪或空=重置居中);服务端校验取值范围;桌面走 IPC,网页走既有命令白名单;保存成功按「轻提示」规范给结果提示(评审建议 F5:调整非当前头像的照片无天然界面反馈,必须提示)。
- **头像渲染**:方形裁剪框 + 全局形状偏好(圆形=圆角遮罩);按裁剪坐标定位缩放;网页端取图沿用既有 blob 通路,凭证不进 URL。
- **照片墙数据**:新只读命令——全部窝的照片,按窝分组、窝内按登记日期倒序、同日期按登记全序、登记内照片按上传序(即排序契约,与头像同源);随载荷带窝名与登记日期。
- **照片墙加载策略(评审建议 F4 最低策略)**:按窝分区渲染,图片进入视口才加载(网页端按需取 blob,桌面直出资源地址+浏览器懒加载);不预取全部图片。
- **照片墙大图**:连翻顺序 = 列表顺序(新→旧,随筛选范围);「查看登记」打开该窝巢况时间线。
- **导航**:顶层页新增「照片」;桌面四页(首页/统计/照片/记录),网页三页(首页/照片/记录);网页端功能边界 = 日常记录+照片回看(词汇表已扩)。
- **形状偏好存储**:存库内设置键值(沿用既有设置存储),双端读、桌面设置页写。
- **不改**:巢况登记现有语义(字段、至少一项非空、日期规则、删除连带)、上传流程(零新增打断)、照片压缩与存储管线。

## Testing Decisions

只测外部行为,不测实现细节;沿用仓库既有同目录测试先例(Vitest 组件/纯函数 + Rust 内联单测):

- Rust:迁移(v11→v12,存量行为空、幂等);裁剪更新校验(合法/越界拒绝/空重置);头像派生投影(同日期多条登记、最新登记无照片跳过、删登记回退、无照片窝为空);照片墙载荷排序契约(跨窝分组、同日期、多照片)。
- Vitest:卡片头像(有照片按裁剪渲染、无照片占位、点击开时间线);形状偏好接线(设置切换全局生效);裁剪编辑器(拖动/缩放产出裁剪、重置、保存调命令、成功轻提示);照片墙(分区/倒序/筛选/连翻顺序与方向/查看登记跳转);导航(双端页项)。
- 全量门槛:vitest 全绿、vue-tsc 0 错、cargo test 全绿。

## Out of Scope

- 照片级单张删除;上传时任何打断(形状/裁剪询问);头像出现在首页卡片以外界面;纯照片登记(D11 未决,留用户决定);缩略图二次生成管线(继续用压缩后照片);照片墙内任何写操作;CONTEXT.md/CLAUDE.md 变更(工作区脏区,夜链不捎带)。
