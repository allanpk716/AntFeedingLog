# 界面交互改进第三轮 Spec（2026-09-19 夜链固化）

> 来源：用户需求 8 条（本会话定稿）+ mock C1-C4 已确认 + 两轮异构盲评（codex/pi，产物 `.xcheck/20260919-115517/`、`.xcheck/20260919-121817/`）。
> 实施细节与逐步代码见执行基线计划 `docs/superpowers/plans/2026-09-19-ui-interaction-round3.md.rev1.md`（含评审附录）；计划与本文冲突时**以本文为准**（本文含复审 round 1 的 8 条修正）。

## Problem Statement

用户在日常使用中遇到 8 个交互痛点：记录页筛不出"某地点的某窝"；右键弹出浏览器原生菜单；编辑记录时系统日历溢出窗口且选完不自动关；筛选条件改完还要点「查询」；查询结果看不出记录属于哪个地点；整页跟着滚动条滚、导航栏会滚出视野且滚动条常驻；首页卡片占地太大、几窝蚂蚁要滚动才能看完；同一窝同一天重复打同一操作没有任何提醒，容易手滑重复记录。

## Solution

1. 记录页加**地点**筛选，选地点后「窝」下拉只列该地点的窝（级联）。
2. 全局屏蔽浏览器右键菜单；文本输入框内保留（右键粘贴）。
3. 全部原生日期/时间控件（11 处）换成**自绘日历**：选中即关、弹层永不超出窗口、带时间快捷键（现在/−10分/＋10分 + 时分步进）；打卡/喂食/编辑场景的日历**带记录标记**（当前操作橙点、其它操作灰点、悬停看当天明细）。
4. 筛选条件变更立即查询，关键词输入停顿 300ms 自动查；去掉「查询」按钮。
5. 查询结果窝名下方灰色小字显示所属地点。
6. 顶栏固定不滚，只有内容区滚动，滚动条不再常驻；默认窗口加大到 960×680。
7. 首页改紧凑卡片：砍开始日期行、操作块压成单行、编辑/冬眠入口收进「⋯」菜单、新建窝挪顶栏。
8. 打卡/喂食/编辑记录时，选中日期已有同操作记录 → 黄条提醒（不拦提交）。

## User Stories

1. 作为饲养者，我想在记录页先选地点再选窝，以便快速看到"公司那窝针毛"的记录。
2. 作为饲养者，我希望在应用里点右键不再出现浏览器菜单（输入框除外），以便它像个桌面应用。
3. 作为饲养者，我想编辑记录时点开日历选一天就立即关闭，以便补录不折腾；且弹层永远不超出窗口。
4. 作为饲养者，我想改任何筛选条件立刻看到结果，以便不用来回移动鼠标点「查询」。
5. 作为饲养者，我想在查询结果里看到每条记录属于哪个地点的哪窝，以便不靠记忆。
6. 作为饲养者，我希望导航栏始终可见、页面不出现多余的滚动条，以便任何窗口高度下都能直接点「记录」「统计」。
7. 作为饲养者，我想打开首页不滚动就看完所有活跃的窝，以便一眼掌握全局。
8. 作为饲养者，我想给某窝打卡时，日历上能看到该窝哪些天做过哪些操作，以便选对日期、避免重复记录。
9. 作为饲养者，我想选到"今天已有同操作记录"的日期时得到黄条提醒，以便确认不是手滑；且真要做第二次也拦不住我。
10. 作为饲养者，我想补录时用「现在/±10分」快捷键和时分步进快速微调时间，以便少敲键盘。

## Implementation Decisions

（模块/接口/契约层面；逐步代码与文件路径见计划 rev1。）

**外壳**：应用根改为 100vh flex 列布局，顶栏 `flex:none` 固定、`.page-body` 唯一滚动容器；html/body/#app 高度 100% 并清默认 margin；各页容器底衬 80px→32px；默认窗口 960×680。右键屏蔽为模块级幂等安装器：重复安装返回同一卸载器；卸载器执行前校验自身仍是当前安装（防止陈旧卸载器清空模块态——复审修正）。

**自绘日历（两组件 + 纯函数库）**：
- 纯函数：月格（周一起排、前置空位）；时间步进语义（复审定稿）：**分钟步进取算术进位**（59+1→下一小时 00）、小时 23↔0 回绕、步进不跨日（跨日走 ±10分/现在）；±10 分整体平移跨日安全。
- DatePickerPop（素版+标记层合一）：props `{ modelValue, placeholder?, markers? }`，markers 为 `Record<ISO日期, {current:boolean, tip:string}>`；事件 `update:modelValue`（选中即关）、`month`（挂载与翻页时通知展示月，供父层拉数据）。**弹层几何（复审修正）**：垂直向空间更大侧展开（不再要求上方>320px 才翻），水平双向钳制（右缘不够左移、且不被推出左缘）。
- DateTimeField = DatePickerPop（日期）+ 时间快捷行：modelValue 与原 datetime-local 同形态 `YYYY-MM-DDTHH:mm`（载荷零改动）；**空值选日期时时间兜底 "00:00"**（复审修正）。
- 替换范围 11 处：打卡/喂食 2、记录页筛选从/到 2、编辑记录 1、新建窝 1、冬眠弹窗 5。

**按窝按月记录查询（新后端命令）**：`colony_month_records(colonyId, year, month, excludeLogId?)` 返回逐日逐操作 `{day, action_id, count, last_time}`；**编辑记录场景传 excludeLogId=当前记录 id**（复审修正：否则编辑弹窗把正在编辑的这条算成重复，只改备注也误报黄条）。月区间按库内定长时间串字典序比较。

**标记与重复提醒纯逻辑**：`buildMarkers(rows, currentActionId, actionNames)`——**actionNames 必须全量**（弹窗侧取 colony.actions 全表 + 当前操作兜底；缺名操作被跳过会导致灰点/tip 整体失效——复审修正）；tip 按 rows 到达序拼接（后端已按 day, action_id 排序）。`duplicateInfo(rows, year, month, dateIso, actionId)` → `{count, lastTime(HH:MM)}` 或 null；黄条文案今天/其它日期两形态。

**弹窗接入（打卡/喂食/编辑）**：月份数据加载带**请求序号守卫**（快速翻月丢弃过期响应）；时间值跨月（现在/±10分/选日期）时**月份自动重同步**（黄条判定依赖）；黄条不拦提交。

**记录页**：LogFilter 加 `location_id`，LogRow 加 `location_name`（未分组为 null，SQL LEFT JOIN location）；级联纯函数（选地点过滤窝选项，原选中窝不在列清空为"全部"）；下拉/日期变更即查；**关键词输入即时同步表单状态、只防抖查询动作**（复审修正：否则重置后输入框残留旧词）；**列表查询带响应序号守卫**（复审修正：旧查询后到不得覆盖新结果）；重置清防抖挂起；窝列下方地点小字（null 显示「未分组」）。

**首页紧凑卡片（方向一，mock C1）**：去开始日期行；操作块单行 chip 两列；饲养天数内联；最近记录单行截断；编辑/开始冬眠/确认出眠/补录冬眠收进「⋯」菜单——**菜单动作执行即收、点卡片外即收**（复审修正），按钮类名保留（v-show 保 DOM，既有测试不破坏）；「＋新建窝」挪顶栏。

## Testing Decisions

- 纯函数（calendar/monthview/loglist 级联/右键安装器）：vitest 直接测语义（含分钟进位边界 00:00−1、幂等卸载→重装→陈旧卸载器序列）。
- 组件（DatePickerPop/DateTimeField）：vue-test-utils；**多步时间断言用"固定基值单步断言"**（复审修正：无 v-model 回写的 mount 下 props 恒为初值，多步链式断言必失败）；`.dp-day` 断言区分 dim 前置格。
- 弹窗（打卡/喂食）：黄条出现/不出现/不拦提交；**灰点集成断言**（fixture 的 colony.actions 必须含第二个操作，防止名字表不全量的回归）；标记月份加载的序号守卫用例可后补，最少保证不抛错。
- 记录页：级联、即改即查、防抖（fake timers）、**防抖挂起时重置不回写旧词**、地点小字、编辑弹窗排除自身（excludeLogId 传入断言）。
- Rust：colony_month_records（分组/跨月排除/排除自身/非法月份）、list_logs（地点筛选、未分组 null、与窝筛选组合）；COUNT 查询补 JOIN colony。
- 每任务提交前全量 `pnpm test`；最终 `cargo test` + `pnpm build`（vue-tsc）双绿。
- 开发时要盯（评审存疑项）：弹层接入真实滚动容器后目检一次有无被祖先 overflow 裁剪——撞上就停下反馈，别默默绕过。

## Out of Scope

- 不引入任何 UI 框架（naive-ui 保持未使用）；不做深色主题；不动统计页图表与通知/备份体系；不改变既有数据 schema（仅新增查询参数与返回字段）；「6 处控件」旧口径作废（实际 11 处）。
