# 蚂蚁饲养记录工具 · 设计共识（2026-09-18）

本文档固化一次设计讨论达成的全部共识，覆盖需求、领域模型、技术选型与界面结构。术语表见 `CONTEXT.md`，壳选型决策记录见 `docs/adr/0001-tauri-2-shell.md`，界面静态示意稿见 `mocks/`（浅色卡片仪表盘已选定为默认方向）。

## 1. 背景与目标

用户养了多窝收获蚁（大头收获蚁、针毛收获蚁，分布在家和公司两处），需要：

- 分别登记每窝的日常维护操作：喂食（种子/干虾仁/面包虫等）、活动区换水、巢穴保湿、垃圾区清理
- 记录每窝开始饲养的日期，展示饲养天数
- 对需要催促的操作（当前为喂食、垃圾清理）给出超期提醒；对水量充足的换水/保湿只登记、不催促
- 支持冬眠期管理：期间提醒静音、临近出眠与出眠日自动提醒
- Windows 上常驻任务栏托盘，随时可看；界面用 web 前端技术实现
- 数据本地存储、可导出备份

## 2. 领域模型

### 2.1 核心对象

| 概念 | 说明 |
|---|---|
| 窝（Colony） | 名字、物种、地点（家/公司/自定义/可空）、开始饲养日期、状态（活跃/冬眠/已结束）。所有记录挂在窝上；同一物种可养多窝，用名字区分 |
| 维护操作（Care Action） | 可扩展字典，预置四种：喂食、活动区换水、巢穴保湿、垃圾清理。每种操作可配置"提醒/登记"性质与建议间隔（见 2.3） |
| 食物（Food） | 可扩展字典，预置：种子、干虾仁、面包虫 |
| 记录（Log Entry） | 一次已发生的维护操作：哪窝 + 哪种操作 + 发生时间 + 备注；喂食记录可挂多种食物（一次投喂多选）。发生时间与录入时间分开存，补录合法（发生时间可早于录入时间） |
| 冬眠期（Hibernation Period） | 开始日期 + 预计结束日期 + 实际结束日期（出眠时回填）；一窝可有多段（约一年一段） |

### 2.2 数据结构（长表流水）

所有操作存统一流水表（一行一次操作），不做每操作一列的宽表——统计的本质是按时间/窝/操作类型分组聚合，长表天生适合，新增操作类型不改表结构。涉及表：窝、操作字典、食物字典、记录流水（含喂食-食物多选关联）、间隔配置、冬眠期。

由此直接支持的统计：任意时间段每窝每类操作次数与频率、喂食食物构成占比、每类操作实际间隔分布（平均/最短/最长）、日历热力图、饲养天数。

### 2.3 提醒类 vs 登记类

每个操作类型在设置里可切换二选一性质：

- **提醒类**：有建议间隔（天数），"距上次"超期在界面标红、可发系统通知。当前配置：喂食（建议 3 天）、垃圾清理（建议 7 天）
- **登记类**：只记录、只显示"距上次 X 天"（中性灰），永不标红催促。当前配置：活动区换水、巢穴保湿——用户用大容量水塔，水量充足，明确表示不需要被催促

### 2.4 冬眠流程

1. 手动开始冬眠：填开始日期 + 预计结束日期（选定开始日期后自动预填默认结束日，可改）
2. 期间：该窝所有超期标红与通知静音；记录照常可以打（如偶尔开箱检查）
3. 预计结束前 N 天（默认 7，可配）提醒"临近出眠，开始留意动静"
4. 预计结束日当天提醒"该恢复日常照顾了"
5. 手动确认出眠：窝回到活跃状态，回填实际结束日期（可与预计不同）
6. 冬眠期从间隔统计中剔除，避免拉长"最长间隔"数字

### 2.5 其他规则

- 窝的删除：没有任何记录的窝可以直接删（建错了）；有记录的窝只能改状态为"已结束"
- 地点是窝的可改字段，首页按地点分组；不追踪搬迁历史（后续需要可新增"搬迁"操作类型）
- 所有记录可编辑、可删除；时间默认"现在"可改

## 3. 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 应用壳 | Tauri 2（复用系统 WebView2） | 安装包 ~10MB、常驻内存低、原生托盘支持；壳层 Rust 基本只有配置，业务逻辑全在前端 |
| 前端 | Vue 3 + Naive UI | 中文文档全、写法直观 |
| 数据 | SQLite（tauri-plugin-sql） | 单文件、好备份好迁移、聚合查询天然顺手 |
| 图表 | ECharts | 日历热力图为内置坐标系、中文文档全 |
| 备份 | 一键导出 CSV / JSON | — |

环境事实：Windows 10 Pro 19045；Node v22.14.0、pnpm 9.15.0、Rust 1.95.0 已安装；单用户单机使用，不需要手机/局域网访问，无多用户无账号。

## 4. 界面结构（浅色主题）

1. **首页（卡片仪表盘）**：按地点分组（🏠 家 / 💼 公司），每窝一张卡：名字、物种、状态徽章、饲养天数（大数字）、四个操作块。操作块 = 一键记录按钮 + "距上次 X 天"状态：提醒类有绿（正常）/红（超期）态，登记类中性灰 + "仅登记"角标。冬眠中的窝：卡片灰化 + 冬眠横幅（入眠日期/预计出眠/剩余天数/临近出眠提醒角标），操作块静音但仍可记录。卡片底部显示最近记录摘要。
2. **喂食弹窗**：点喂食块弹出：食物多选（chips）、时间（默认现在、可补录）、备注（可选）；确认后记录并刷新状态。
3. **统计页**：日历热力图（一天一格、悬停看当天明细）、喂食构成占比（环形图）、每周操作次数（柱状）、实际间隔 vs 建议间隔（仅提醒类画建议刻度，登记类标注"仅登记"）。可按窝、按时间范围筛选。
4. **记录列表页**：按窝/操作类型/时间范围筛选，备注可搜索；记录可编辑、可删除。
5. **托盘与常驻**：点窗口关闭 = 最小化到托盘（右键菜单退出）；悬停 tooltip 一句话概要；开机自启默认开（设置可关）；Windows 通知默认关（设置可开）。
6. **设置**：操作/食物字典管理（增删改、提醒/登记性质、建议间隔）、通知开关、开机自启、数据导出。

## 5. 明确不做（v1）

- 不记喂食数量、不存照片
- 不做多用户/账号/云同步
- 不做手机端/局域网访问
- 不做历史数据批量导入
- 不做每窝单独的建议间隔（全局一套）
- 不做"按日期自动进冬眠"（只手动）
