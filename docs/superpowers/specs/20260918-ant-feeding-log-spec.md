# 蚂蚁饲养记录（AntFeedingLog）· 实施 Spec

日期：2026-09-18 ｜ 来源：`20260918-ant-feeding-log-consensus.rev1.md`（含文末评审附录 11 条已核实规则）＋ 两轮盲评产物 ｜ 术语：遵守仓库 `CONTEXT.md`

## Problem Statement

用户在家里和公司养了几窝收获蚁（大头收获蚁、针毛收获蚁），喂食、换水、保湿、清垃圾这些日常照料全靠记忆，没有登记、没有提醒。需要一个常驻 Windows 任务栏的本地工具：每窝分开记账、该催的（喂食、垃圾清理）到点提醒、不该催的（大容量水塔的换水、保湿）只登记；冬眠期自动闭嘴、临近出眠再叫人；还要能看历史规律（频率、食物构成、间隔）。

## Solution（用户视角）

一个托盘常驻的 Windows 桌面应用。打开就是按地点分组的窝卡片墙：每窝一张卡，卡片上每个操作一个按钮，点一下就记完一笔；喂食会多弹一步选食物（可多选）。卡片实时显示"距上次 X 天"——提醒类超期变红并弹 Windows 通知，登记类永远灰色安静。冬眠的窝整卡灰化、提醒静音，快出眠时提前 7 天打招呼。另有统计页（热力图、食物占比、间隔节奏）和记录流水页。数据是一个本地 SQLite 文件，一键安全备份、一键导出归档。

## User Stories

1. 作为饲养者，我想新建一窝并填名字、物种、地点、开始饲养日期，以便多窝不混淆（名字必填且唯一）。
2. 作为饲养者，我想管理地点清单（家/公司/自定义），以便首页按地点分组查看。
3. 作为饲养者，我想在窝卡片上点一下就记录一次喂食/换水/保湿/清理，以便 3 秒记完一笔。
4. 作为饲养者，喂食时我想一次勾选多种食物（种子、干虾仁、面包虫…），并可补录时间和写备注。
5. 作为饲养者，我想看到每类操作"距上次 X 天"，提醒类超过建议间隔变红，以便一眼知道哪窝欠照料。
6. 作为饲养者，换水和保湿我只想登记、永远不要被催（水塔水量大），界面上标"仅登记"。
7. 作为饲养者，我想自己新增操作类型和食物种类（如"糖水""降温"），并可停用不再用的。
8. 作为饲养者，停用某食物/操作后，我想旧记录里它照常显示、编辑旧记录时还能保留它。
9. 作为饲养者，我想给每类操作设置"提醒/仅登记"性质和提醒类的建议间隔天数。
10. 作为饲养者，我想给一窝开始冬眠（填开始日和预计结束日），期间所有提醒静音、但仍能记账（如偶尔检查）。
11. 作为饲养者，预计出眠前 7 天我想收到"快出眠了"的提醒，出眠日当天再收一次"该恢复照顾了"。
12. 作为饲养者，我想手动确认出眠（实际出眠日和预计不同没关系），出眠后"距上次"从出眠日重新起算、不会一睁眼全红。
13. 作为饲养者，我想看到每窝已饲养天数（含冬眠的自然日天数）。
14. 作为饲养者，我想在统计页看日历热力图（一天一格，悬停看当天明细）。
15. 作为饲养者，我想看喂食的食物构成占比（环形图，按出现次数归一化，图例带次数）。
16. 作为饲养者，我想看每类操作的实际间隔 vs 建议间隔（冬眠天数已扣除），以便发现"最近保湿拖长了"。
17. 作为饲养者，我想按窝、按时间范围筛选统计。
18. 作为饲养者，我想在记录流水页按窝/操作/时间筛选、搜备注，并改错、删错。
19. 作为饲养者，我想让应用常驻任务栏：关窗口只是收进托盘、开机自启、悬停看一眼概要。
20. 作为饲养者，我想一键安全备份数据、一键导出 CSV/JSON 归档带走。
21. 作为饲养者，通知太吵时我想整体或分类关掉（超期提醒、冬眠提醒分开关）。
22. 作为饲养者，已结束（送人/死亡）的窝我想归档到底部折叠区，不删历史。

## Implementation Decisions

### 架构与模块

- **应用壳**：Tauri 2（复用系统 WebView2），托盘常驻、关窗即最小化到托盘、右键托盘退出；开机自启默认开（插件能力，设置可关）。
- **前端**：Vue 3 + TypeScript + Naive UI + ECharts；三页 + 设置（首页卡片仪表盘 / 统计 / 记录列表），浅色主题，视觉基线 = `mocks/mock-a-light.html`。
- **数据层唯一属主是 Rust（rusqlite，`journal_mode=DELETE`，单库文件自洽）**：前端一律经 Tauri command 读写，不用前端 SQL 插件；schema 迁移在 Rust 启动时按 `user_version` 逐版本顺序执行（只升不降）。提醒调度（启动即查 + 每 30 分钟）与通知发送同在 Rust 侧定时任务，不依赖前端定时器。

### 数据 schema（契约级）

- **colony**：id、名字（trim 后全局唯一）、物种、地点（可空，外键）、开始饲养日期、状态（活跃/冬眠/已结束）、排序。
- **care_action**：id、名字、图标、性质（提醒/仅登记）、建议间隔天数（仅提醒类有意义，登记类也保留可编辑值以便日后切换）、启用位、排序。预置四条：喂食(提醒,3天)、活动区换水(仅登记)、巢穴保湿(仅登记)、垃圾清理(提醒,7天)。
- **food**：id、名字、启用位、排序。预置：种子、干虾仁、面包虫。
- **location**：id、名字、启用位、排序。预置：家、公司。
- **care_log**：id、窝、操作、发生时间、备注、录入时间（两时间分开存，补录合法）。
- **log_food**：记录-食物多选关联（仅喂食记录有）。
- **hibernation**：id、窝、开始日期、预计结束日期、实际结束日期（空=开放段）。约束：同窝各段不得重叠；结束日期 ≥ 开始日期；每窝至多一段开放段；已结束的窝不可开始冬眠；状态联动=开始冬眠→状态置冬眠、确认出眠→回填实际结束+状态回活跃；回填历史段不改当前状态。
- **reminder_ledger**：已发提醒台账：窝、提醒种类（超期/临近出眠/出眠日）、操作（超期类才有）、基准日。身份=(窝,种类,操作,基准日)，唯一。
- **settings**（键值）：通知总开关（默认开）、超期提醒开关（默认开）、冬眠提醒开关（默认开）、临近出眠提前天数（默认 7）、开机自启（默认开）。

### 行为规则（评审附录钉死的 11 条，全部纳入）

1. 提醒调度：启动即查 + 每 30 分钟；通知默认开，总/分类开关。
2. 台账去重：身份=(窝,种类,操作,基准日)；超期提醒每个超期日最多一条（同日不重发）；临近出眠=预计出眠日前 N 天起首次检查发一次；出眠日=当天一次；修改预计出眠日后，**未发**的临近/出眠提醒按新日期重算（删未发记录），已发的不追回。
3. 补发上限：错过检查后补发时，每窝每种提醒只补最新一条，且该基准日在近 7 天内；更旧的不再补（界面红标照常显示）。
4. 出眠提醒仅对状态=冬眠的窝生效，提前出眠后不再触发。
5. "距上次"：出眠后基准 = max(最近一次记录, 出眠日期)；任何记录增删改后界面即时重算（数据驱动，无定时延迟）。
6. 间隔统计：相邻两次记录间隔若与冬眠段重叠，扣除重叠天数；多段冬眠各自适用。
7. 频率统计分母 = 筛选范围自然日天数（不扣冬眠），界面标注口径。
8. 食物占比 = 各食物出现次数 / 范围内食物出现总次数（归一化 100%），图例同时显示次数；一次多选投喂每种所选食物各计 1 次。
9. 饲养天数 = 今天 − 开始饲养日期的自然日天数（含冬眠），首页与统计一致。
10. 字典删除规则：未被引用可物理删；被引用只能停用；停用项不出现在新建记录入口/筛选默认项，但编辑旧记录时原引用项照常显示（标"已停用"）且可保留；改名只改显示名，历史跟随。
11. 备份：设置里"安全备份"由 Rust 复制库文件到用户选定目录（无 WAL，拷贝即完整）；帮助文案写明手动拷贝需先从托盘真实退出；导出 CSV/JSON 定位为归档带走，不是恢复通道。

### API 契约（Tauri command，前端可见的全部入口）

窝：listColonies（含每窝各操作距上次/超期态、最近记录摘要）、createColony、updateColony、archiveColony(置已结束)、deleteColony(仅无记录)。
记录：logCare(窝,操作,发生时间,备注[,食物数组])、updateLog、deleteLog、listLogs(筛选:窝/操作/时间范围/备注关键词,分页)。
字典：actions/foods/locations 各自 list/save(增改)/deactivate/erase(仅未引用)；setActionPolicy(性质+建议间隔)。
冬眠：startHibernation(窝,开始,预计结束)、confirmWake(窝,实际结束)、listHibernations(窝)。
统计：getStats(窝(可空),时间范围)→{按日操作数[],食物占比[],每周操作数[],各操作间隔统计[]}。
系统：getSettings、setSettings、exportData(格式,目标路径)、backupTo(目标路径)、revealDataFolder。

### 界面（基线 = mocks）

首页：地点分组（清单顺序，空地点"未分组"最后）；卡片=名字/物种/状态徽章/饲养天数大数字/动态操作块（每个启用中操作一块，2 列自适应）；提醒类红绿态、登记类灰+"仅登记"角标；冬眠卡灰化+横幅（入眠/预计出眠/剩余天数/临近提醒角标）；已结束折叠区。喂食弹窗：食物多选 chips+时间(默认现在可改)+备注。统计页：热力图/占比环/每周柱/间隔条(仅提醒类画建议刻度)+筛选。记录列表：筛选+搜索+行内编辑删除。设置：字典管理/通知开关/自启/数据文件夹/备份/导出。托盘：tooltip 一句话概要（如"2 窝活跃 · 大头一号喂食超期 1 天"）。

## Testing Decisions（只测外部行为）

- **Rust 单测**（cargo test）：迁移链（空库→v1）；窝名唯一校验；冬眠约束（重叠/日期/唯一开放段/状态联动/已结束不可入眠）；"距上次"出眠重置；间隔扣冬眠天数（含多段）；台账身份去重与改预计出眠日的重算；补发上限（最新 1 条 + 7 天窗）；journal DELETE 下备份拷贝完整性。
- **前端单测**（vitest，纯逻辑不挂载真实 DOM 也可）：红/绿/灰状态判定（提醒类 vs 登记类 vs 冬眠静音）；占比归一化计算；饲养天数；筛选逻辑。
- **手动冒烟**（每票验收时人工过一遍对应路径）：界面交互、通知真弹出、托盘行为——自动化不做 UI 端到端。
- 仓库无既有测试先例，以上即先例。

## Out of Scope（v1 明确不做）

喂食数量、照片；多用户/账号/云同步；手机/局域网访问；应用内 JSON/CSV 导入恢复（恢复=拷 .db，导入列 v2）；每窝单独建议间隔（全局一套）；按日期自动进冬眠；暗色主题。
