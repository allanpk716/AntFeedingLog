# AntFeedingLog · 蚂蚁饲养日志

Windows 桌面的多窝蚂蚁饲养记录工具：一键记账、超期提醒、冬眠管理、统计图表。本地单机、数据自持，常驻任务栏托盘。

专为收获蚁（大头收获蚁、针毛收获蚁等）饲养场景设计，也适用于任何需要"分窝记账 + 定时提醒"的小动物日常照料。

## 功能

- **多窝管理**：每窝独立名字/物种/地点（家、公司…自定义）/开始饲养日期；首页按地点分组，卡片显示已饲养天数；已结束（送人/死亡）的窝归档折叠不删数据
- **一键记账**：喂食（种子/干虾仁/面包虫…可多选）、活动区换水、巢穴保湿、垃圾清理——卡片上点一下即记完；操作类型与食物均可自定义增删
- **提醒 / 仅登记**：喂食、垃圾清理按可配置的建议间隔超期标红并发 Windows 通知；用大容量水塔的换水/保湿可设为"仅登记"，只记录、永不催促
- **冬眠管理**：手动入眠（填预计出眠日）→ 期间提醒静音、仍可记账 → 临近出眠提前提醒 → 出眠日提醒 → 手动确认出眠；统计自动扣除冬眠天数，出眠后"距上次"重新起算
- **统计**：日历热力图（悬停看当天明细）、喂食食物构成占比、每周操作次数、实际间隔 vs 建议间隔；按窝与时间范围筛选
- **记录流水**：按窝/操作/时间筛选、备注搜索、行内编辑、删除；补录历史时间合法
- **数据自持**：SQLite 单文件（`journal_mode=DELETE`，拷贝即完整备份）；**自动备份**（每天第一次新数据时备一份到指定目录、保留份数可配、失败静默自动补跑）+ **应用内从备份整库恢复**（摘要预览 / 恢复前自动快照 / 失败当前库零改动）+ 一键安全备份、导出 CSV（Excel 直开，含公式注入防护）/ JSON
- **日志与异常退出溯源**：错误与关键动作流水按天滚动落盘（留 14 天），设置页可看最近错误摘要、打开日志文件夹；崩溃/强杀后下次启动显示"上次异常退出"
- **托盘常驻**：关窗即收进托盘、开机自启、悬停显示概要（"2 窝活跃 · 某窝喂食超期 1 天"）；单实例
- **地点级联筛选**：记录页先选地点再选窝，「窝」下拉只列该地点的窝；换地点后原选中窝不在列自动清空
- **桌面化右键**：全局屏蔽浏览器原生右键菜单（输入框内保留，右键粘贴不受影响）
- **自绘日历**：12 处原生日期控件（冬眠 6、打卡/喂食 2、记录页筛选 2、编辑 1、新建窝 1）全部换成自绘日历——点一天即选即关、弹层永不超出窗口、时间快捷键（现在/±10 分钟/时分步进）；打卡/喂食/编辑场景日历带记录标记（当前操作橙点、其它操作灰点、悬停看当天明细）
- **即改即查**：记录页筛选条件一改立即出结果，关键词输入停顿约 300 毫秒自动查，不再需要点「查询」按钮
- **窝列地点**：查询结果每条记录的窝名下方灰色小字标所属地点（未分组明示「未分组」）
- **固定顶栏独立滚动**：导航栏固定不滚、只有内容区滚动，滚动条不再常驻；默认窗口加大到 960×680
- **首页紧凑卡片**：操作块压成单行、饲养天数内联，编辑/冬眠等低频入口收进「⋯」菜单、新建窝挪顶栏——小窗口不滚动看完全部活跃的窝
- **重复提醒不拦提交**：打卡/喂食/编辑时选中已有同操作记录的日期弹黄条提醒（今天/历史日期两种文案），确认不是手滑要记第二次也照常保存

## 技术栈

Tauri 2（Rust + rusqlite 独占数据层，逐版本迁移链）· Vue 3 + TypeScript · ECharts · Vitest

## 开发

```bash
pnpm install
pnpm tauri dev          # 开发运行（首次 Rust 编译约 5-10 分钟）
pnpm test               # 前端测试（300 个）
cd src-tauri && cargo test   # Rust 测试（303 个）
pnpm tauri build        # 打包安装包
```

数据文件位于 `%APPDATA%/com.antfeedinglog.app/`，设置里有"打开数据文件夹"。

发新版（打 tag → GitHub Actions 自动构建签名发布 → 验收产物）看 [docs/release.md](./docs/release.md)。

> **发版硬依赖：更新签名密钥对（私钥 + 密码）。** 私钥存在 GitHub Secrets（`TAURI_SIGNING_PRIVATE_KEY` / `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`），原件在开发机 `~/.tauri/`；**灾备副本与恢复说明存放在群晖 Drive 同步目录的 `AntFeedingLog` 文件夹**（含 README）。私钥或密码一旦丢失，已装用户将永远无法收到应用内更新（只能换密钥对并让所有人手动重装）。
