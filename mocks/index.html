🐜 蚂蚁饲养日志 · 界面示意稿

三份静态假数据稿，双击或点开对比。建议用 Edge / Chrome 打开。
mock A · 卡片仪表盘（浅色）首页
每窝一张卡片，按地点分组；四个一键记录按钮 + "距上次 X 天 / 超期"状态灯；含冬眠中卡片的演示。点"喂食"会弹食物多选窗口。
mock A · 卡片仪表盘（深色）首页 · 同款换主题
与上面完全相同的布局和交互，换成深色主题。正式版也可以做成"深浅可切换"，先看你更喜欢哪个当默认。
mock B · 统计页第二页
日历热力图（悬停看当天明细）、喂食构成占比、每周操作次数、实际间隔 vs 建议间隔。左上角可以切换窝、切换时间范围，都能点。
mock C1 · 首页改版 · 方向一：紧凑卡片交互改进轮
顶栏固定、内容区独立滚动；卡片压扁——砍开始日期、操作块改单行 chip、编辑/冬眠收进「···」、新建窝挪顶栏。5 窝以内一屏看完不用滚。
mock C2 · 首页改版 · 方向二：行式列表交互改进轮
一窝一行，信息密度最高，同样高度能放更多窝；行内 chip 就是打卡入口，冬眠提示压成行内小条。和方向一对比着看，选一个。
mock C3 · 记录页改版交互改进轮
地点筛选（地点→窝级联）、条件变更即查（无查询按钮，关键词停 0.3 秒自动查）、窝名下挂地点、自绘素版日历（可点）。筛选真的能用，试试。
mock C4 · 自绘日历 + 重复提醒交互改进轮
打卡面板的新日历：橙点=该窝当天已有当前操作、灰点=其它操作（悬停看明细）；选到已有记录的日期出黄条提醒。时间快捷键「现在/±10分」。可点。
看的时候可以留意：卡片上还想多看到什么信息？按钮的排布顺不顺手？热力图/占比图对你有没有用？——都记下来告诉我，正式版照改。
